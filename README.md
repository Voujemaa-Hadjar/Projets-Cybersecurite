# Cas Pratiques, Labs & Playbooks (Système & Support IT)

Afin d'accompagner mes compétences en sécurité, je réalise et documente des playbooks techniques et des résolutions d'incidents issus de mon parcours d'apprentissage. Savoir formaliser une procédure claire et exploitable est une compétence indispensable pour structurer et administrer l'infrastructure d'une entreprise.

- **Mini Lab Microsoft : Déploiement Active Directory** – Création d'un domaine virtuel (`supportlab.local`) sous Windows Server 2022 et jonction d'un poste client Windows 11. Ce playbook valide l'adressage réseau statique, la résolution DNS de base et la gestion de l'annuaire utilisateur.
